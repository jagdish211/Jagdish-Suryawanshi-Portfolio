# Jagdish Pravin Suryawanshi — Data Scientist Portfolio

A responsive Data Scientist portfolio built with HTML5, CSS3 and Vanilla JavaScript.

## Features
- Dark / Light mode
- Responsive mobile navigation
- Profile photo placeholder using `assets/profile.jpg`
- Project filtering
- Project details modal
- Animated counters
- Scroll reveal animations
- Contact form validation
- Resume download button
- SEO metadata
- No React/Vue/Angular

## Add Your Photo
Replace:
`assets/profile.jpg`

with your real professional photograph.

## Add Your Resume
Replace:
`assets/Jagdish_Suryawanshi_Resume.pdf`

with your actual PDF resume.

## Personalize
Update GitHub, LinkedIn and email links in `index.html`.

## Run
Open `index.html` in a browser. No server is required.
